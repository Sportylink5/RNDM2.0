# Перед публикацией v64

Гонки отсутствуют. Прежний Supabase оставлен без миграции данных. В приложении остаётся только прежний публичный ключ; роли не берутся из user_metadata. Серверные функции v64 не применялись.

Сервер является источником прав. Общие закрепы и роли появляются после подключения функций из SETUP_CHANNELS_V64_RU.md. Назначение ролей ограничено владельцем через RLS и RPC с SECURITY INVOKER; единственный SECURITY DEFINER — закрытый помощник, возвращающий роль текущего пользователя. Существующие политики нужно проверить совместно с новыми: добавочные политики не отменяют прежние широкие разрешения.

Проверить под двумя аккаунтами запрет чтения чужих чатов и файлов, редактирования чужих постов, назначения ролей читателем, закрепа поста другого канала. Проверить anon-доступ, Storage и Realtime. Для reports требуется разрешённый INSERT собственного reporter_id и чтение подтверждённого ID: клиент не может создать такие права.

Это описание мер и ограничений, а не заключение об аудите действующей базы. Браузерные, сетевые и RLS проверки на действующих аккаунтах обязательны перед публичным запуском.
