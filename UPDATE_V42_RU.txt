RNDM CHAT v42 — РУЛЕТКА И ОФОРМЛЕНИЕ ПРОФИЛЯ

ГЛАВНАЯ ФИШКА: РАНДОМНЫЙ ЧАТ
Открой «Рулетка» из нижнего меню на телефоне или из бокового меню на ПК.
Выбери язык и общую тему, нажми «Начать поиск».
При совпадении можно открыть личный чат, посмотреть профиль собеседника или искать другого человека.
Остановка поиска удаляет свою запись из очереди; при уходе в фон поиск останавливается.
Подбор работает только при добровольном нажатии на «Начать поиск».
Он учитывает взаимные блокировки, ограничения профилей и запреты на личные сообщения.

ПОИСК НЕ НАЧИНАЕТСЯ?
Настройки → Общение и приватность: разреши личные сообщения всем,
включи «Показываться в поиске» и отключи «Закрытый профиль».
Для реального совпадения два человека должны одновременно начать поиск с совместимыми фильтрами.
Если второй пользователь не ищет, отображается экран ожидания — это нормально.

ОФОРМЛЕНИЕ ПРОФИЛЯ
Настройки → Оформление профиля: выбери 1 из 7 фонов, 1 из 6 рамок
и индивидуальный цвет профиля. Вверху показан живой предпросмотр.
Нажми «Сохранить оформление» — данные запишутся в таблицу Supabase public.profiles.
Это отдельные настройки от цветов интерфейса и обложки-фотографии.
Загруженная обложка-фотография имеет приоритет над цветным фоном.

ПУБЛИКАЦИЯ НА GITHUB PAGES
Извлеки ZIP и загрузи все файлы в корень репозитория.
Папок и SQL-файлов внутри ZIP нет.
Backend-изменения для подключённого проекта Supabase уже применены.
После обновления открой новую страницу или переустанови приложение с экрана Домой,
если iPhone держит старые файлы в кэше.

ПРОВЕРКИ И ОГРАНИЧЕНИЯ
Проверен синтаксис JS, рендер четырёх состояний UI, мобильная ширина,
обязательные статические файлы и структура ZIP.
Не выполнено реальное end-to-end тестирование подбора двух зарегистрированных аккаунтов
на опубликованном GitHub Pages — это потребует двух живых сессий.
