# Проверки v64

`npm test` — 36 тестов, все прошли. Тесты используют изолированную базу и инертные DOM-объекты. Проверены порядок запросов, поздние ответы, черновики, офлайн, подтверждение отправки, безопасный HTML, пагинация, архив/непрочитанные, клипы и остановка медиа.

Новые проверки: разделение ID канала и чата в папках; ограничения повреждённых настроек; безопасные ссылки; отсутствие утечки ссылок удалённых/будущих/истёкших сообщений или соседнего чата; атомарное сохранение настроек клипов при ошибке; обработка отсутствующих серверных функций и отказа доступа; редактирование канала и сохранение текста при отказе; QR без вставки содержимого в SVG.

Дополнительно два URL профиля успешно декодированы независимым jsQR 1.4.0 из реальных QR-матриц; декодер использован только для проверки и не входит в приложение.

Браузерная проверка, реальная работа двух аккаунтов и выполнение SQL не проводились: браузерный инструмент отсутствует, доступ к проекту через подключённые аккаунты не предоставлен. Для каналов приложена подготовленная серверная настройка, не применённая в действующей базе.
