RNDM CHAT v59.1 — LIQUID GLASS + КАНАЛ «ТАПАЛКА»
===================================================

ЧТО ИЗМЕНЕНО
- Полностью обновлены поверхности интерфейса: эффект жидкого стекла, прозрачные панели,
  мягкие отражения, контрастные состояния, светлая/тёмная тема, собственные цвета пользователя.
- Унифицированы иконки: чёткие встроенные SVG вместо растровых иконок в управляющих кнопках.
- Вместо перегруженной навигации: Чаты / Контакты / Рулетка / Каналы / Клипы / Ещё.
- В «Ещё» перенесены Звонки, Избранное, Уведомления, Звёзды и подарки, Настройки,
  Поддержать RNDM, а для персонала — Админка.
- Убраны повторяющиеся быстрые кнопки в шапке списка, промокарточка рулетки над чатами
  и кнопка доната на пустом экране.
- Убраны лишние кнопки в шапке переписки и кнопка отложенной отправки из поля ввода.
  Поиск по сообщениям, подарки и отложенная отправка доступны в меню чата «…».
- «Котик · Тапалка» восстановлен как закреплённый игровой канал в разделе «Каналы».
  При открытии доступны нажатия, энергия, прокачка, задания, облики и облачный рейтинг.
  Отдельной кнопки на панели навигации нет, всё находится внутри каналов.
- Удалена только отдельная мини-игра RNDM World из пользовательского интерфейса.
  Команды /solo и /group больше не запускают игру; текст отправляется как обычное сообщение.
  Старый roadworld.html заменён страницей перенаправления на RNDM Chat.
- Версия файлов и кэш PWA обновлены до 59.1.0. База Supabase и аккаунты НЕ сбрасываются.

КАК ОБНОВИТЬ САЙТ НА GITHUB PAGES
1. Сохрани копию предыдущего релиза и текущего репозитория.
2. Открой ZIP и загрузи ВСЕ файлы из архива в КОРЕНЬ репозитория GitHub,
   где находится index.html. Файлы не нужно помещать во вложенную папку.
3. Замени существующие одноимённые файлы. Добавь НОВЫЙ liquid-glass.css.
4. Удали из репозитория старые roadworld.js и roadworld.css,
   если эти файлы остались после прошлой версии. roadworld.html оставь: теперь это
   безопасное перенаправление для старых закладок.
5. Нажми Commit changes. Дождись успешного развёртывания GitHub Pages.
6. Открой адрес сайта в приватном окне; затем проверь обычное окно и установленную PWA.
   Сервис-воркер сам сменит кэш. Если видны элементы старой версии, полностью
   закрой и снова открой PWA; в крайнем случае обнови кэш сайта.
7. В Supabase НЕ нужно создавать новый проект и НЕТ новых SQL-скриптов в релизе.
   Старые настройки Authentication, Storage, RLS, RPC и Auth Hooks должны сохраниться.

ПРОВЕРЬ ПЕРЕД ПУБЛИЧНЫМ РЕЛИЗОМ
- Вход, регистрация и восстановление пароля через почту.
- Чат двух настоящих аккаунтов: открытие, отправка, получение, редактирование,
  удаление, вложения, сохранённые, отложенные сообщения и поиск по переписке.
- Создание и публикации в группах и каналах, истории, клипы и комментарии.
- Голосовые и видеозвонки с ДВУХ разных устройств/сетей (для стабильности нужен TURN).
- Звёзды, подарки, донаты/кейсы, уведомления и доступ к админке по роли.
- Safari iPhone, Chrome Android, Chrome/Edge PC, PWA после обновления версии.
- Легальность текстов privacy.html и работа защищённых RPC/политик RLS в Supabase.

ВАЖНО
- В данном окружении выполнены статические проверки скриптов, ссылок и макетов
  при ширине 320, 390 и 1440 пикселей. Реальные действия в Supabase, платёжные
  операции и звонки по сети НЕ проверялись; перед открытым релизом нужен живой QA.
- Это НЕ сквозное шифрование. Конфиденциальность и права модерации описаны отдельно.
- Игровой интерфейс RNDM World удалён; таблицы и RPC «Тапалки» используются как прежде.
  Ранее созданные игровые таблицы и RPC Supabase
  на сервере не удалялись, чтобы случайно не повредить пользовательские данные.
