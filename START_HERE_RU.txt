RNDM CHAT 33 — АДМИНКА, ЗВОНКИ, КЛИПЫ, GITHUB PAGES

Сайт готов к публикации как обычный HTML/CSS/JavaScript-проект.
BAT-файл и сборка на компьютере не нужны.
Начни с GITHUB_PAGES_RU.txt: инструкция для публикации через GitHub.

Добавлено:
- Админка: пользователи, жалобы, публикации и журнал действий.
- Доступ для существующих ролей owner, admin и moderator.
- Аудио- и видеозвонки прямо из личного чата.
- Входящий вызов, принятие/отклонение, микрофон, камера, завершение.
- История звонков и повторный вызов.
- Клипы: старая лента, загрузка видео, лайки, сохранения, комментарии,
  ссылки на клип, удаление собственной публикации.
- Кнопка включения звука, когда браузер блокирует автоматический старт.
- Навигация на телефоне с доступом к новым разделам.
- Относительные пути, совместимые с подкаталогом GitHub Pages.

Сохранены прежние база Supabase, интерфейс, истории и пользовательские цвета.
Все подключения находятся в config.js. Ключ публичный, пригодный для браузера.
Существующие таблицы, функции и хранилища используются без изменения схемы.
Для работы сайта SQL запускать не нужно. Блокировки, изменение ролей
и удаление через админку выключены до согласования исправлений доступа
в базе. Подробнее: ADMIN_RU.txt. Предложение SQL не применялось.

Как пользоваться:
Админка → пункт меню или Настройки → Открыть админку (для сотрудников).
Чаты → личный чат → телефон или камера.
Клипы → Выложить → видео до 50 МБ → Опубликовать.
Настройки → Оформление → Твои цвета.
Над списком чатов → Моя история.

Сайт запускается по опубликованной HTTPS-ссылке.
Открытие index.html двойным щелчком не подходит для ES-модулей.

Проверка и её ограничения: CHECKS_RU.txt.
Настройка TURN для сложных сетей: CALLS_NETWORK_RU.txt.
