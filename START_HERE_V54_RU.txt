RNDM Chat v54 — Подарки, кейсы и донаты

Изменения: 38 подарков (12 старых + 18 новых + 8 эксклюзивов), 3 кейса за 50/150/500 игровых звёзд, инвентарь, отправка приза другу, добровольная поддержка сайта, заявки на проверку оплаты и Owner-панель.

ВАЖНО: платежи никак не покупают кейсы, игровые звёзды или случайные награды. Деньги нельзя вывести из игры, а призы не обмениваются на деньги.

ПОРЯДОК УСТАНОВКИ:
1. Создай резервную копию базы и файлов v53.
2. В существующем проекте Supabase открой SQL Editor и выполни RNDM_v54_INSTALL.sql. Файл нужен именно для новых таблиц и защищённых функций. Ранее данные и чаты не удаляются.
3. Распакуй остальные файлы v54 в корень GitHub Pages-репозитория (без вложенных папок).
4. Заново войди в аккаунт на телефоне, обнови PWA-кеш (версия 54.0.0).
5. Владелец: Админка → Донаты → добавь HTTPS-ссылку на свою платёжную страницу. До добавления ссылки пользователи не смогут подать заявку.
6. Проверь Звёзды → кейсы → инвентарь. Открой кейс аккаунтом с достаточным игровым балансом; проверь сохранение приза и списание.
7. Для подтверждения доната владелец вручную сверяет номер операции в кабинете провайдера и только потом отмечает заявку.

Сервис оплаты не задан: укажи свою ссылку в панели. Автоматический webhook провайдера не настроен.

Кейсы по звёздам и шансам:
Базовый 50 ⭐ — обычные 80%, редкие 18%, эксклюзивы 2%.
Премиум 150 ⭐ — обычные 50%, редкие 40%, эксклюзивы 10%.
Легендарный 500 ⭐ — обычные 20%, редкие 55%, эксклюзивы 25%.

Шанс каждой группы указан; внутри группы подарок выбирается равновероятно. Результат определяется на сервере, а не в JavaScript.

Требуется тест в браузере с пользовательской сессией — не проводился.
