RNDM CHAT v72 — восстановлены Racing v70 + Conquest v71

ВНИМАНИЕ: это патч изменённых файлов, не полный мессенджер.

УСТАНОВКА
1. Сначала сделай резервную копию работающего RNDM Chat.
2. Скопируй все файлы из ZIP в корень сайта, замени совпадающие по имени.
3. Не удаляй старые обязательные файлы: config.js, supabase-2.117.2.js, core.js, api.js, CSS, остальные страницы, файлы и медиа.
4. Обнови сайт на HTTPS и перезагрузи PWA (Service Worker v72).
5. Игры → Гонки / FPS / Conquest: Москва.

РЕЗУЛЬТАТ
- Гонки: исходный улучшенный Racing v70 с 4 трассами, уровнями ботов, 3D-подобным рендером и управлением с ПК/телефона.
- Conquest: существующий v71 с серверным общим миром Supabase, командами и реальными домами OSM.
- FPS: сохранён из гоночного патча.
- Возвращены файлы arcade-race-render.js, arcade-net.js, arcade-engine.js — нельзя оставлять их старые версии.

БАЗА
Проект RNDM уже содержит таблицы cq71_* и функции. Выполнен частичный импорт 1420 уникальных зданий OSM в разных местах Москвы. НЕ ВСЯ МОСКВА.
Для полного покрытия нужна отдельная большая выгрузка OSM и импорт через import_moscow_osm.py.
Текущий OSM импортер использует широкую рамку Москвы, а не точную административную границу — для выпуска стоит добавить строгую геометрию границы.

ОГРАНИЧЕНИЯ
Патч собран на основе предоставленного Racing v70 и серверного Conquest v71. Он не установлен на GitHub Pages и не проверен на живой паре игровых аккаунтов. Если сайт изменился после v70, проверь конфликты.
Не вставляй секретные ключи Supabase / DATABASE_URL в HTML или GitHub.
