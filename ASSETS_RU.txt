ИКОНКИ RNDM

Основные иконки созданы встроенным генератором изображений и вставлены
в кнопки приложения. Файл: icons.png, прозрачный PNG 1448 x 1086.
Это единый атлас из 4 столбцов и 3 строк; каждая ячейка — 362 x 362.

Порядок слева направо:
1-й ряд: чаты / контакты / каналы / избранное.
2-й ряд: настройки / поиск / вложение / эмодзи.
3-й ряд: микрофон / отправка / добавить / назад.

Описание для генерации:
Transparent production UI icon atlas for RNDM Chat, exactly 4 columns and
3 rows, equal centered cells, crisp rounded vector-like outlines, medium
violet main strokes and small mint accents. Icons: overlapping chat bubbles,
contacts, megaphone, bookmark, gear, search, paperclip, smile, microphone,
paper plane, plus, left arrow. Generous equal padding, consistent stroke width,
no grid, no labels, no shadows, no glow, no 3D, genuinely transparent backdrop.

Вспомогательные иконки меню нарисованы в SVG в core.js.
Шрифт Inter включён локально; лицензия — OFL-Inter.txt.
Библиотека Supabase 2.117.2 включена локально, как в прежней версии.
Её лицензия — LICENSE-supabase.txt.
