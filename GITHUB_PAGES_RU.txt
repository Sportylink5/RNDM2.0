RNDM CHAT 33 — ЗАПУСК НА GITHUB PAGES БЕЗ BAT

1. Распакуй архив на компьютере.
2. Открой свой репозиторий GitHub → Add file → Upload files.
3. Загрузи СОДЕРЖИМОЕ распакованной папки, а не сам ZIP.
   В корне репозитория должны лежать index.html, config.js,
   manifest.webmanifest и папки app, assets, vendor.
   При замене старого сайта замени файлы с теми же именами.
4. Нажми Commit changes.
5. Открой Settings → Pages.
6. Source: Deploy from a branch.
7. Branch: main; Folder: /(root); нажми Save.
   Если у тебя главная ветка называется иначе, выбери её.
8. Дождись успешной публикации. В Settings → Pages появится ссылка:
   https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/
9. Открой именно эту ссылку. На Windows ничего запускать не нужно.
   Сайт будет работать, даже когда твой компьютер выключен.

Если файлы загружаешь через веб-интерфейс и .nojekyll не попал на GitHub,
создай его через Add file → Create new file. Имя: .nojekyll;
добавь одну пустую строку и сохрани. Для обычного HTML он необязателен,
но исключает обработку сайта генератором Jekyll.

Не открывай ссылку на index.html внутри github.com и не загружай только ZIP:
это просмотр кода, а не опубликованный сайт.

БАЗА И ВХОД
В config.js оставлен прежний проект Supabase и публичный ключ.
Для публикации сайта новая база и SQL не нужны. Ограничения админки
и ожидающие согласования исправления описаны в ADMIN_RU.txt. После смены адреса сайта войди снова.
Для писем регистрации и восстановления пароля в Supabase:
Authentication → URL Configuration → Redirect URLs добавь
https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/index.html
https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/reset-password.html?recovery=1
Site URL можно установить на адрес опубликованного сайта.
Точный адрес определяется именем твоего аккаунта и репозитория.

ЗВОНКИ
Открой личный чат. Телефон — аудио, камера — видео.
Оба участника должны войти в аккаунты и открыть сайт.
Разреши микрофон; для видео также разреши камеру.
Входящий вызов появляется сверху, даже в разделе клипов или настроек.
История вызовов находится в разделе «Звонки».
Кнопка микрофона выключает/включает его; камера управляется отдельно.
По завершении звонка камера и микрофон освобождаются.

Клиент использует WebRTC и прежние серверные функции звонков.
В комплекте настроен STUN. Для сетей, блокирующих прямое соединение,
нужен действующий TURN-сервер. Старые общие реквизиты OpenRelay
не используются, поскольку текущая документация требует свои реквизиты.
Подробнее и пример настройки — CALLS_NETWORK_RU.txt.

КЛИПЫ
Раздел «Клипы» → «Выложить» → выбери видео → описание → «Опубликовать».
Поддерживаются MP4, WebM и MOV до 50 МБ. Для совместимости рекомендуем
MP4 с видео H.264 и звуком AAC; отдельные кодеки MOV поддерживаются не везде.
Лайки и сохранения записываются в прежнюю базу; комментарии видны другим.
Видео пытается воспроизводиться со звуком. Если браузер запрещает
автозапуск со звуком, появится кнопка «Нажми, чтобы включить звук».
Это ограничение браузера. На телефоне следующий клип открывается свайпом.

АДМИНКА
Войди в существующий аккаунт владельца, администратора или модератора.
Открой «Админка» в меню либо «Настройки» → «Открыть админку».
Прямая ссылка: admin.html внутри опубликованного сайта.
Подробности и ограничения — ADMIN_RU.txt.
