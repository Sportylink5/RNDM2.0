RNDM CHAT v45 — ОБЩЕЕ ОБНОВЛЕНИЕ

НОВОЕ
• Рулетка: сохранён реальный поиск по языку/темам через сервер. Добавлены подарок и заявка в друзья после совпадения.
• Профили: музыка по HTTPS, публикации со своей лентой и закреплением, оформление/рамки/обложки, коллекция полученных подарков.
• Звёзды: серверный кошелёк и отправка подарков остались из v44. Подарки получили более заметные редкие оформления.
• Клипы: вкладки Новые / Популярные / Подписки, фильтр по хештегу, подписка и подарок автору, переход в профиль.
• Тапалка: игровая энергия, восстановление, ежедневные задания (4+8+12 звёзд), уровни, улучшения энергии/скорости за звёзды, серверные ограничения накрутки.
• Чаты: прежние реакции, поиск, закрепление и черновики сохранены; добавлена отложенная отправка и простой редактор фотографии (поворот, яркость, ч/б).
• Настройки: расширен словарь русского/английского интерфейса и добавлена диагностика WebRTC/микрофона/TURN.
• Безопасность: сервер блокирует отдельные явные угрозы в сообщениях, клипах, комментариях и публикациях; лимиты сообщений были предусмотрены ранее. Это не полноценная автоматическая модерация всего вредного контента.

УСТАНОВКА
1. Распакуй ZIP. Внутри файлы без папок; замени все файлы в корне репозитория GitHub Pages.
2. Дождись новой публикации. Открой HTTPS-сайт в Safari и полностью перезапусти установленное приложение (если осталось старое — добавь на главный экран заново).
3. Схема подключённого Supabase уже обновлена: вручную применять SQL не требуется.
4. Настрой собственный TURN-сервер для надёжных звонков из разных мобильных сетей: см. CALLS_NETWORK_RU.txt. STUN без TURN работает не во всех сетях.

ПРОВЕРКА
JS синтаксис и импорт/пути, изолированный браузерный тест мобильной и десктопной верстки; БД функции/политики проверены. Тестов реальных звонков и отправки между двумя пользовательскими устройствами не было. Полный перевод каждой надписи пока не завершён.
