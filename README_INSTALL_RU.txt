RNDM CONQUEST v71 — РЕАЛЬНЫЕ ДОМА МОСКВЫ, ЕДИНЫЙ ОНЛАЙН-МИР
=============================================================

ЧТО ВНУТРИ
- Интеграция в ЕЩЁ -> ИГРЫ -> CONQUEST: МОСКВА.
- Создание своей команды при первом входе: название (3–32 символа), флаг, уникальный цвет.
- ОДИН мир для всех вошедших пользователей RNDM. НЕТ локального деморежима.
- Реальная подложка OpenStreetMap. Отдельные РЕАЛЬНЫЕ геометрии зданий из OSM.
- Каждое импортированное здание — отдельный объект с единым владельцем.
- Разведчик (40): пустое здание захватывается сразу; занятое требует переброски армии.
- Разведка показывает силы защитников на 15 минут, затем требует новой проверки.
- Разведка после первого штаба доступна в пределах 1,6 км от собственных зданий.
- В своих зданиях можно нанять бойцов (120/5) и поставить блокпост (220/уровень).
- Переброска армии между зданиями <=4,5 км; исход боя рассчитывает SQL сервер.
- Движение отображается на общей карте; обновления через Realtime + резервный опрос.
- Управление мышью/колесом на ПК, перетаскиванием/двумя пальцами на телефонах.
- Существующие RNDM Racing/FPS и чаты в этом патче не удалены.

ВАЖНО: АРХИВ — ИСХОДНИКИ И МИГРАЦИИ, НЕ ОПУБЛИКОВАННАЯ ОНЛАЙН-ИГРА
В этом сеансе подключённый Supabase не показывает ни одного проекта. Поэтому
таблицы НЕ установлены, реальные здания Москвы НЕ импортированы и многопользовательский
сценарий на 2 разных реальных аккаунтах НЕ проверялся. Пока не выполнены шаги ниже,
игра честно покажет ошибку подключения / пустые данные, а не ложный локальный онлайн.

1. СДЕЛАЙ КОПИЮ работающего RNDM Chat и базы Supabase.
2. Архив сделан на базе патча RNDM v70 (из v68/v69). Если сайт после v70 уже менялся,
   НЕ заменяй app.js/index.html вслепую: перенеси в свою новую версию отдельные вставки
   для Games из этих файлов.
3. В корень сайта: ЗАМЕНИ index.html, app.js, arcade.js, sw.js, pwa-register.js.
   ДОБАВЬ conquest.js, conquest.css, conquest.html. Все остальные файлы оставь.
   conquest.html содержит игру в одном HTML (CSS+JS встроены), но загружает
   существующие библиотеку Supabase и config.js от RNDM для АВТОРИЗАЦИИ.
   Войти в Conquest можно через Игры, отдельную HTML-ссылку публиковать необязательно.
4. В существующем проекте Supabase -> SQL Editor выполни CONQUEST_V71_SUPABASE.sql.
   ВАЖНО: версии v70 conquest_* и новые cq71_* не конфликтуют; старые таблицы не удаляются.
5. В SQL Editor выполни CONQUEST_V71_CRON.sql. Это включает разрешение приказов 24/7.
   Если на тарифе/сервере недоступен Cron, запланируй вызов
   `select public.cq71_resolve_arrivals(50)` каждые 60 сек в защищённом бэкенде.
6. ПОДГОТОВЬ РЕАЛЬНЫЕ ГЕОМЕТРИИ ДОМОВ МОСКВЫ (обязательный этап):
   - Возьми актуальный OpenStreetMap .osm.pbf, покрывающий ВЕСЬ ГОРОД,
     ВКЛЮЧАЯ Новую Москву и Зеленоград; городской extract без этих территорий не подойдёт.
   - На своём ПК/сервере: pip install osmium 'psycopg[binary]'
   - Установи DATABASE_URL как СЕКРЕТНУЮ строку подключения к PostgreSQL.
   - Запусти: python import_moscow_osm.py path/to/moscow.osm.pbf
   - Этот скрипт загружает дома-ways и мультиполигоны-relations, не трогает владельцев.
   - Скрипт фильтрует по широкому прямоугольнику всей Москвы, поэтому также могут
     попасть дома Московской области. Для строгой административной границы нужен
     отдельный полигон Москвы и фильтрация по нему.
   - ЗАГРУЗКА ВСЕХ зданий требует места и ресурсов базы; проверь тариф Supabase.
   - DATABASE_URL / service_role НИКОГДА НЕ КОПИРУЙ В HTML, JS или GitHub Pages.
7. Разверни сайт на HTTPS (например GitHub Pages). На обеих устройствах войди в разные
   аккаунты RNDM. Первый игрок выбирает свободный дом -> разведчик -> захват.
   Второй игрок создаёт СОБСТВЕННУЮ команду с другим цветом и ищет соседний дом.
   Договоритесь о точке конфликта: разведка занятых домов, набор гарнизона,
   отправка войск, ожидание обработки Cron, наблюдение за цветом захваченного дома.
8. Перезагрузи приложение. Если используется PWA, дождись обновления service worker
   или очисти кеш приложения только при необходимости.

О ПОДЛОЖКЕ КАРТЫ
По умолчанию показана настоящая карта OpenStreetMap (tile.openstreetmap.org).
Сервис OSM предназначен для умеренного интерактивного использования, не для огромной MMO:
https://operations.osmfoundation.org/policies/tiles/
Перед массовым релизом ОБЯЗАТЕЛЬНО настрой лицензированный tile-провайдер
или собственный тайловый сервер. Для смены адреса можно задать ДО загрузки игры:
window.RNDM_CONQUEST_TILE_URL='https://your-tiles/{z}/{x}/{y}.png';
Проверь условия провайдера, лицензию ODbL и атрибуцию. Google Maps и Яндекс.Карты
НЕ встроены: без их API-ключей/лицензий нельзя законно использовать их тайлы в игре.

ПРОВЕРКИ
- Синтаксис JS, интеграция файла в раздел Games — проверены локально.
- UI и последовательность: создание команды, разведка, набор бойцов, блокпост,
  вкладки и отсутствие горизонтального скролла — проверены на эмуляциях 1440×900,
  390×844 и 844×390 с тестовыми ответами сервера.
- SQL миграции и импорт нескольких сотен тысяч объектов в реальной базе НЕ проверены.
- На большой MMO-нагрузке (1000+ соединений) потребуются нагрузочное тестирование,
  кеш геоданных, оптимизация realtime потоков и стабильный tile-провайдер.
- Карта отображает реальные дома только после полного импорта исходной OSM базы.
- Нет точного маршрута по дорогам и полноценного тактического 3D-боя — это основы
  серверного RTS с временем перемещения и разрешением сражения по прибытии.
