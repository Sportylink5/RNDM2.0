RNDM Chat v67.0 — ТОЛЬКО ИЗМЕНЁННЫЕ ФАЙЛЫ (v66.0 -> v67.0)

Этот архив — обновление для RNDM Chat v66.0.
Внутри находятся только изменённые файлы веб-сайта: 24 шт.

Как обновить GitHub Pages:
1. Распакуйте архив.
2. В репозитории с установленной RNDM Chat v66.0 замените одноимённые файлы файлами из архива, сохраняя пути.
3. НЕ удаляйте все остальные файлы проекта — они нужны для работы мессенджера.
4. Сохраните/загрузите изменения в GitHub, дождитесь обновления сайта и обновите вкладку (при необходимости перезагрузите без кэша).

Что добавлено: в админке Owner может выдавать и отзывать доступ к RNDM Together для отдельных пользователей.
Правила Supabase уже обновлялись ранее; этот патч не включает и не требует повторного применения SQL.

Важно: этот патч рассчитан на v66.0. Если у вас другая версия, сравните её с базовой прежде чем заменять файлы.
