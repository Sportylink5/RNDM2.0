RNDM CONQUEST v70 — HTML + ПАТЧ ДЛЯ RNDM CHAT
==================================================

ДВА СПОСОБА ЗАПУСКА:
1. conquest.html — ОДИН HTML-ФАЙЛ. Внутри весь CSS и JS. Открой через браузер,
   чтобы посмотреть дизайн, карту всей Москвы и поиграть ЛОКАЛЬНО.
   Это именно ДЕМОВЕРСИЯ, а не общий сервер и не мультиплеер.
   Для картографических подложек необходим интернет.
2. Интеграция с RNDM Chat v68 / v69 — используй файловый патч из этого архива.
   Игроки входят через существующую авторизацию мессенджера.
   Игру открывают из ЕЩЁ -> ИГРЫ -> CONQUEST: МОСКВА.
   Уже существующие гонки и FPS остаются.

УСТАНОВКА В МЕССЕНДЖЕР
- Сделай резервную копию текущего сайта и Supabase.
- В КОРНЕ САЙТА замени index.html, app.js, arcade.js, sw.js, pwa-register.js.
- Добавь conquest.js, conquest.css и необязательный отдельный conquest.html.
- Прочие файлы мессенджера НЕ УДАЛЯЙ; архив содержит только изменённые.
- В Supabase (на проекте этого же мессенджера) открой SQL Editor и выполни
  CONQUEST_SUPABASE.sql. Он создаёт НОВЫЕ таблицы/функции conquest_*,
  не удаляет и не меняет таблицы чатов.
- Залей файлы на GitHub Pages. Перезагрузи RNDM Chat и открой «Игры».
- Проверь на 2 реальных аккаунтах (ПК + телефон): захват, блокпост,
  создание отряда, движение, атака, отображение изменений другого игрока.

ЧТО УЛУЧШЕНО
- Полноэкранная тактическая карта Москвы (не ограничена одним районом).
- Участки закрашены как территории на подложке реального города.
- Секции: Участок, Армия, Задачи + краткая оперативная сводка.
- Мобильная панель команд, адаптация под узкий экран и горизонтальный режим.
- При недоступном сервере явно включается ЛОКАЛЬНОЕ ДЕМО, не притворяющееся онлайн.
- Локальная демоверсия работает даже в conquest.html с сохранением в браузере.
- В настоящем онлайн-режиме все захваты и экономика проходят через RPC Supabase.
- Сохранены гонки и FPS, пользовательские аккаунты и существующие чаты.

ВАЖНО: ЭТО НЕ ПОЛНОСТЬЮ ГОТОВАЯ MMO
- Отдельный conquest.html — только локальное демо; онлайн — через мессенджер + SQL.
- В чате v70 онлайн будет функционировать только после применения SQL и при
  доступном Supabase-проекте, где пользователи реально авторизованы.
- Мир работает по сетке кварталов, не отдельным физическим квартирам и дорогам.
- Границы игры пока заданы прямоугольником, который охватывает Москву,
  Новую Москву и Зеленоград, включая часть прилегающей области.
- Карта — растровые тайлы CARTO/OSM и требует разрешённого провайдера для
  массовой нагрузки. Использование публичного tile CDN ограничено правилами.
- Нет серверного движения по уличной сети, кланов, экономики тысяч игроков,
  полноценного 3D/строительства, тестирования под высокой нагрузкой.
- Подключённый Supabase не предоставляет в этой сессии пользовательские проекты,
  поэтому миграция НЕ выполнялась и настоящий онлайн проверить невозможно.
- Текущий патч делался на базе v68+v69, не заменяй им неизвестную более новую версию
  без проверки совместимости. SQL ставить на том же проекте RNDM.
