RNDM 2.0 — мобильный фикс догонялок v75

Положите ВСЕ файлы из этого архива в КОРЕНЬ сайта RNDM (рядом с существующим index.html), соглашаясь на замену.
Не удаляйте остальные файлы и не запускайте SQL: Supabase и база не изменяются.

Где искать:
RNDM → Ещё → Игры → Догонялки. На телефонах откроется отдельная полноэкранная страница, но на том же сайте и с той же учётной записью.
Там сразу видны условия матча и кнопки создания лобби, после создания — список друзей с приглашениями и кнопка старта.
После старта появляется карта, джойстик слева, ускорение справа, мини-карта. Кнопка ☰ в игре открывает список участников/кнопку выхода.
Назад: «Все игры» → RNDM ?view=games.
Приглашения через уведомления RNDM открывают страницу догонялок.

Важно: база данных для комнат была настроена ранее; матч с двумя реальными телефонами нужно проверить после выкладки на рабочий сайт.
Если на iPhone установлено PWA, перезапустите его; при предложении обновления нажмите «Обновить». Версия ресурсов 75.0.0.
