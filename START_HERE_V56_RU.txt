RNDM CHAT v56 — ПОДАРКИ С ОБНОВЛЕННЫМИ ИКОНКАМИ · ПОЛНОСТЬЮ БЕЗ ПАПОК

Пакет для GitHub Pages: все файлы в корне архива, ни одной вложенной папки.
38 индивидуальных изображений подарков gift-<id>.webp: иллюстрации объемных предметов вместо старых плоских пиктограмм.
В views.js изменен путь к иконкам с gift-icons/<id>.webp на gift-<id>.webp.
В sw.js исправлены пути к предварительно кэшируемым иконкам и повышена версия кэша PWA.
Логика чатов, профилей, обмена подарков (10%), кейсов и донатов сохранена из v55.

УСТАНОВКА
1) Перед заменой скачай резервную копию репозитория.
2) Распакуй архив и загрузи все файлы в КОРЕНЬ репозитория GitHub Pages (рядом с index.html).
3) Удали прежнюю папку gift-icons/ из репозитория — она больше не используется в версии v56.
4) Обнови сайт, при необходимости очисти кэш/PWA на телефоне.
5) Проверь каталог иконок и отправку подарков.

Для этой косметической версии новых SQL-изменений не требуется: серверная версия v55 уже в Supabase.
